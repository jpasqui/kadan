title: Guides
description: Guides for creating Pikmin 4 mods with Kadan.
---

Before you start, you'll need Unreal Engine 4.26 and the files from your own copy of
Pikmin 4 version 1.1.1. If this is your first time here, then start with
[Install Kadan](/guides/install/).

| Guide | What you will do |
| --- | --- |
| [Install Kadan](/guides/install/) | Add Kadan to an Unreal project. |
| [Import from the game](/guides/import/) | Bring the game's maps and assets into your project. |
| [Create a map](/guides/create-a-map/) | Build a new area from an empty level. |
| [Edit a map](/guides/edit-a-map/) | Add actors and change objects in one of the game's maps. |
| [Export a mod](/guides/export/) | Turn your changes into a mod. |
| [Work on several mods](/guides/several-mods/) | Keep more than one mod in the same project. |
| [The Kadan panel](/guides/kadan-panel/) | Look up any button or field in the Kadan panel. |

Use Unreal Editor to make maps, meshes, textures, sounds, materials, Blueprints, and widgets.
You can also edit data tables and create treasures, creatures, and Pikmin types. Kadan imports
what you need from the game and [exports your selection](/guides/export/) as one mod.

:::caution[WIP]
Table edits export, but they haven't been tested in the game yet. Kadan can't export new maps,
or new treasures, creatures, and Pikmin types, yet.
:::

The mods that you export are loaded by [Tsuchi](https://tsuchi.jpasqui.dev/), so you'll need
to install it to play them.
