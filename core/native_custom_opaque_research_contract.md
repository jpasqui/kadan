# Held opaque creator material path

The creator's `UMaterial` supplies the live graph recipe. The asset intended for
the game is a fresh parameter-free `MaterialInstanceConstant`, plus a format3
shader set containing complete newly compiled programs. A cooked Windows
`UMaterial` shader map is not admitted by this path.

The first recipe supports Surface, Opaque, one DefaultLit shading model,
single-sided rendering, constants, and the selected local static-mesh factory.
Texture/function/collection parameters and other factories remain unsupported.
The selected original material's actual package chain, archive references,
serialized decal response and bounded directional-source specialization select
the complete program. Source settings default compatibility is recorded
separately from original ARM64 constructor evidence.

`CompileOpaqueResearchTemplate` reads actual package bytes and the archive,
derives per-pass identities and sealed scene/storage bindings, then returns own
programs and a recipe. Its map identity is `CookedShaderMapIdHash`. The archive's
resource hash serves archive lookup only. No original instruction program or
assembly is returned as a creator payload.

The native editor producer requires an unchanged original parent reconstructed
through the actual source reader. The parent record's
`header-body-sha256-v1` digest must match SHA256(header || body) from the selected
source, with the actual source class, package and inherited settings. A prior
JSON-MD5 baseline or placeholder does not satisfy this association. Source
imports and their dependencies are research references, with renderer/family/
production admission withheld.

The producer constructs and saves a new instance without duplicating a game
object, parameters, static resources or shader maps. A targeted native Windows
cook waits for asynchronous writes and restores editor package metadata before
readback. `ReadFreshOpaqueInstanceCook` accepts only the exact parent reference,
empty parameter lists, inactive inherited settings and the constructor-generated
texture-reference cache. It requires an absent lazy-GUID word and no native
shader-map tail. The actual source clip and ordered cache are external typed
expectations, not inferred from matching bytes.

Stock cook summary `FolderName="None"` does not prove the mod namespace. The
native owner, cook destination, export leaf and later verified container census
establish that association. Byte inspection alone never mints a source proof.

The privately constructed `FP4OpaqueResearchInstanceProof` retains actual live
object identities, graph/native-field fingerprints and saved/cooked/set/recipe
file hashes. Revalidation detects source-record changes and transient native
edits even if the package was never marked dirty. It is a session capability,
with no restart or JSON claim admission.

Whole-program independent compiler matches, original no-resource instance-tail
parity and stock serializer facts are separate evidence from an actual fresh
cook. A successful fresh cook remains separate from selected mesh/permutation
qualification, container custody and rendered game acceptance. Every research
result currently has `ProductionAdmitted=false`; this path does not widen the
mod file whitelist or publish a mod.
